# 📊 Sales Analytics Dashboard

A modern, interactive **Sales Analytics Dashboard** built with HTML, CSS, JavaScript, Chart.js, and Supabase.

The dashboard helps visualize **revenue, sales performance, daily metrics, KPIs, and sales representative rankings** in a clean and responsive interface.

## ✨ Features

- 📈 Daily revenue trend chart
- 💰 KPI cards for revenue, sales, average order value, and best day
- 🏆 Sales representative leaderboard
- 📊 Detailed sales representative report
- 📅 Daily sales metrics
- 📥 CSV data export
- 🔄 Supabase API data fetching
- 🌙 Dark/Light theme
- 📱 Responsive dashboard UI
- ⚠️ Loading and error handling

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Chart.js
- Supabase RPC API

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Configure your Supabase API settings in `script.js`.
4. Run the project using a local development server.
5. Open the dashboard in your browser.

## 📌 Dashboard Sections

- **Dashboard** — KPIs, revenue trends, insights, and leaderboard.
- **Sales Report** — Representative-wise sales and revenue analysis.
- **Daily Metrics** — Date-wise sales and revenue data.
- **Settings** — Report date and theme controls.

## 📥 Data Export

The dashboard allows users to export daily sales metrics as a **CSV file** directly from the browser.

## 🔐 Security

Do not commit private Supabase service-role keys or other sensitive credentials to a public repository. Use appropriate Supabase security policies and a secure backend/environment configuration where required.
